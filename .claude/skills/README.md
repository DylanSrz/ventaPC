# Skills de Claude Code

Las 14 skills de diseño de [Emil Kowalski](https://github.com/emilkowalski/skills)
(licencia MIT, ver `LICENSE-emilkowalski-skills.txt`), guardadas en el repo para
que estén disponibles en cada sesión de Claude Code, en la nube o en local.

| Skill | Para qué sirve |
| --- | --- |
| `emil-design-eng` | Filosofía de pulido de interfaces y detalles de diseño |
| `review-animations` | Revisa animaciones existentes con un estándar alto |
| `improve-animations` | Audita todas las animaciones y propone un plan de mejoras |
| `find-animation-opportunities` | Busca dónde agregar movimiento (y dónde no) |
| `animate` | Construye animaciones web nuevas |
| `mobile-native` | Ajustes para que la web se sienta como app en el celular |
| `break-ui` | Prueba la interfaz con datos extremos |
| `apple-design` | Diseño y movimiento al estilo Apple, para la web |
| `animation-vocabulary` | Glosario para ponerle nombre exacto a un efecto de animación |
| `prototype` | Crea varias versiones de un componente para elegir entre ellas |
| `pick-ui-library` | Recomienda la librería de frontend adecuada para cada tarea |
| `ask-sonner` | Guía de Sonner, librería de notificaciones (toasts) para React |
| `animate-expo` | Animaciones y gestos en apps React Native / Expo |
| `write-swift` | Cómo escribir Swift moderno (apps de Apple) |

Para actualizarlas: `npx skills@latest add emilkowalski/skills -s '<nombre>' -a claude-code`
(sin `-g`, para que se instalen en este proyecto).
